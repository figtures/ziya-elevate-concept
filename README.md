# Ziya Şakir Yılmaz

Ziya Şakir Yılmaz’ın eğitimlerini, konuşmalarını, yayınlarını ve Başarı Mühendisliği yaklaşımını sunan iki dilli kurumsal web sitesi.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
